# CHIP Cardiologie contentregister — openbare demo

Openbare GitHub Pages-versie van het Inforium CHIP contentregister voor de fictieve afdeling Cardiologie van Hartstad Ziekenhuis.

De demo toont onder meer:

- 25 voorbeelden van patiëntinformatie, vakinformatie en gekoppelde bronnen;
- Inforiums en Inforium Notes vanuit Inforium CHIP;
- zoeken en filteren op type, status, zorgpad en contentprovider;
- invoer van nieuwe voorbeeldcontent met automatisch contentpaspoort-ID en SHA-256-hash;
- registratie van licenties, beoordelaar en inhoudelijke goedkeuring.

Nieuwe invoer wordt in de GitHub Pages-versie uitsluitend in de lokale browser opgeslagen. De technische koppeling met het centrale CHIP-contentregister volgt later.
